# Анализ рынка труда: вакансии аналитиков данных (Работа России)

Проект по сбору и анализу вакансий с портала «Работа России» через открытый API.
Цель — понять, какие навыки требуют работодатели, в каких регионах больше всего
вакансий и какие зарплаты предлагают.

## 🎯 Задачи

1. Собрать вакансии по запросам «аналитик данных», «data analyst», «бизнес-аналитик», «системный аналитик».
2. Проанализировать географию вакансий.
3. Определить топ-компаний по количеству вакансий.
4. Посчитать средние зарплаты.
5. Выявить самые востребованные навыки.

## 🛠️ Инструменты

- Python (requests, pandas, matplotlib)
- API «Работа России» (opendata.trudvsem.ru)
- Jupyter / IDLE

## 📊 Результаты

### 1. География вакансий

| Регион | Количество вакансий |
|--------|---------------------|
| Москва | 77 |
| Санкт-Петербург | 33 |
| Свердловская область | 20 |
| Самарская область | 19 |
| Республика Татарстан | 13 |

**Вывод:** Больше всего вакансий — в Москве и Санкт-Петербурге. Это ожидаемо: там сосредоточены головные офисы крупных компаний. Однако удалённая работа стирает географические границы — аналитик может работать из любого региона.

### 2. Топ-компаний

| Компания | Количество вакансий |
|----------|---------------------|
| Сбербанк России, ПАО | 36 |
| АО "РТ ЛАБС" | 6 |
| СПБ ГКУ "СПБ ИАЦ" | 4 |

**Вывод:** Сбербанк — крупнейший работодатель для аналитиков. Это подтверждает, что банковская сфера — один из главных потребителей аналитики.

### 3. Зарплаты

| Показатель | Значение |
|------------|----------|
| Средняя минимальная | 91 450 ₽ |
| Медиана | 74 500 ₽ |
| Минимум | 27 093 ₽ |
| Максимум | 350 000 ₽ |

**Вывод:** Разброс зарплат огромный — от 27 тыс. до 350 тыс. руб. Медиана (74 500 ₽) ниже средней (91 450 ₽), что говорит о наличии высокооплачиваемых вакансий, которые «тянут» среднее вверх.

## 💡 Общий вывод

Рынок труда для аналитиков данных в России активен: только на портале «Работа России»
мы нашли 281 уникальную вакансию. Основные работодатели — банки и IT-компании.
Ключевые навыки: SQL, Excel, Python. Средняя зарплата — около 91 000 ₽.

## 🚀 Как запустить

1. Установите зависимости:
   pip install requests pandas matplotlib
2. Запустите сбор данных:
   python trudvsem_parser.py
3. Запустите анализ:
   python trudvsem_analysis.py
